DoomLinux
Boots Doom. Every time.

Minimal Linux Live ISO

Build a bootable OS that drops straight into Doom.

DoomLinux compiles the Linux kernel, BusyBox, and FBDoom from source, then assembles a bootable ISO that launches Doom on boot. One script. Deterministic output.

Test

Smoke tests verify artifacts and optional QEMU checks.

What the script does

  • Downloads kernel, BusyBox, and FBDoom sources.
  • Compiles everything statically where possible.
  • Builds initramfs and ISO boot assets.
  • Ships a bootable ISO that runs Doom on startup.

Artifact layout

Generated assets live in predictable folders.
